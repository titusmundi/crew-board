# Crew Board

The daily working tool: schedule, materials and tools for every live job, in one page. The owner
edits it directly; it saves itself. **The board is the record for dates; this note records the
reasons.**

## What is on it
| Tab | What it does |
| --- | --- |
| **Schedule** | Monday to Friday calendar plus a weekend column. A Today card. Alerts for double-bookings and past tasks not ticked off. A By project view. |
| **Materials** | Per job, sorted by the date each item must be on site. Ticks: Ordered, Received. |
| **Tools** | Grouped by day and site. Tick: On site. |

**Colours:** <job: colour>.

## What the owner can do alone
Drag a task (press and hold on a phone), open a day, mark done, move to a date, delete (tap twice),
add a one-off task, undo, tick materials and tools.

## What still needs Claude
A new job or colour; a chain of moves; realigning material dates; holiday changes.

## How saving works
| Status | Meaning |
| --- | --- |
| **Saved to board** | Everything is on the board, visible from any device. |
| **Unsaved changes · Save now** | A save is due within a few seconds. |
| **Changes on this device only** | Not yet on the board. Press Save now. |
| **Saved on this device only** | The board cannot save from where it is open. |
| **Read-only view** | Opened by someone who cannot edit it. |
